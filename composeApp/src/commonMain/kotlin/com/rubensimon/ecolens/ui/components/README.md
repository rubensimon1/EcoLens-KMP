# Componentes (Components) - Capa Común

Este paquete contiene todos los componentes visuales reutilizables de Jetpack Compose que conforman la interfaz de EcoLens.

## Propósito
Albergar elementos UI que se utilizan en múltiples pantallas para asegurar la consistencia del diseño y evitar la duplicación de código.

## Ejemplos de Componentes
*   Botones personalizados (EcoLensButton).
*   Campos de texto con diseño específico.
*   Tarjetas, modales, alertas y barras de progreso.
*   Componentes compartidos de la cámara o de información de reciclaje.
