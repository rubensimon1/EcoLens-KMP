# Pantallas (Screens) - Capa Común

Este paquete agrupa todas las pantallas de la interfaz de usuario de la aplicación, separadas lógicamente por flujo.

## Subpaquetes Principales
*   **auth**: Pantallas relacionadas con la autenticación (Login, Registro, Recuperación de contraseña).
*   **main**: Pantallas principales del usuario una vez que ha iniciado sesión (Inicio, Perfil).
*   **features**: Pantallas de las características específicas de la app (Cámara para reciclaje, Mapa de contenedores, Clasificaciones).

Esta organización permite encontrar rápidamente cualquier vista de la aplicación de manera estructurada.
