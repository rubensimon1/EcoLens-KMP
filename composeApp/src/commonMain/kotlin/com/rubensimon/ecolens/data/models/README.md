# Modelos de Datos (Models) - Capa Común

Este paquete contiene las clases de datos (Data Classes) y modelos que representan el dominio de la aplicación EcoLens.

## Propósito
Definir la estructura de la información que fluye a lo largo de la aplicación. Estos modelos se utilizan en repositorios, UI y red.

## Subpaquetes
*   **auth**: Modelos relacionados con sesión, tokens y perfil de usuario.
*   **maps**: Modelos de coordenadas, puntos de interés y contenedores de reciclaje.
*   **items**: Modelos que representan objetos detectados, categorías de reciclaje y estadísticas.
*   **social**: (Si aplica) Modelos de amigos, ranking y recompensas.
