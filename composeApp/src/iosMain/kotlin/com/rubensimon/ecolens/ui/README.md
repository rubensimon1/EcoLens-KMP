# Interfaz de Usuario (UI) - iOS

Este paquete contiene la configuración de la Interfaz de Usuario (UI) nativa para iOS y el punto de entrada de la aplicación en los dispositivos de Apple.

## Propósito
Alojar el código Swift/Kotlin Native necesario para arrancar Jetpack Compose Multiplatform en el ecosistema iOS, o para crear vistas nativas específicas (UIKit / SwiftUI) si fuesen necesarias por rendimiento o integración nativa.

## Uso Común
*   Implementación de `MainViewController` para enlazar Compose Multiplatform con la aplicación de iOS.
*   Envoltorios (Wrappers) de vistas nativas como el mapa de Apple o la cámara de iOS.
